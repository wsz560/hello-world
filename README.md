# hello-world

我的 C 语言练习仓库，记录从零开始的编程学习过程。

---

## 程序列表

| 文件名 | 说明 | 主要知识点 |
|--------|------|-----------|
| `test.c` | 第一个 C 程序，输出 Hello World | printf、main 函数 |
| `100.c` | 找零计算程序：输入价格，输出应找金额 | 变量、scanf、算术运算 |
| `practice.c` | 成绩统计程序：输入成绩直到 -1，输出总人数、总分、平均分 | while 循环、累加、类型转换 |
| `circle.c` | 计算圆的面积：输入半径，输出面积 | 浮点数运算、格式化输出 |
| `1.c` | 求和判断程序：输入三个数，判断和是否大于50 | 输入验证、条件判断、浮点数累加 |

---

## 环境

- 编辑器：VS Code
- 编译器：MinGW-w64（gcc）
- 系统：Windows 11

---

## 如何运行

1. 打开终端，进入代码所在目录
2. 编译：`gcc 文件名.c -o 文件名.exe`
3. 运行：`./文件名.exe`

示例：
```bash
gcc 1.c -o 1.exe
./1.exe
