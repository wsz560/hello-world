# hello-world

这是我的 C 语言练习仓库，记录从零开始的编程学习过程。

## AI 辅助说明

`student.c` 在编写过程中使用了 DeepSeek AI 作为辅助工具，用于解释结构体和数组的相关概念，其他程序均为本人独立完成。

## 程序列表

| 文件名 | 功能 | 主要知识点 |
|--------|------|-----------|
| `test.c` | 输出 Hello World | printf、main 函数 |
| `change.c` | 找零计算程序 | 变量、scanf、算术运算 |
| `circle.c` | 计算圆面积 | 浮点数、输入输出 |
| `sum_compare.c` | 输入三个数，判断和是否大于50 | 条件判断 |
| `odd.c` | 输入 n，打印 1 到 n 之间的所有奇数 | for循环、条件判断 |
| `score_stat.c` | 成绩统计（输入成绩直到-1，输出总人数和平均分） | while循环、累加 |
| `student.c` | 学生成绩统计（录入姓名和成绩，输出总分、平均分、最高/最低分） | 结构体、数组、循环遍历（AI辅助） |

## 课堂作业（第四次上机）

| 文件名 | 功能 | 主要知识点 |
|--------|------|-----------|
| `判断奇偶.c` | 输入一个整数，判断并输出奇数或偶数 | if-else、取模运算 |
| `判断成绩.c` | 输入 0~100 的成绩，输出优秀 / 良好 / 及格 / 不及格 | 多分支 if-else、区间判断 |
| `简易计算器.c` | 输入两个整数和一个运算符，完成加、减、乘、除 | switch 分支、字符输入 |
| `判断字符.c` | 判断输入字符是数字、大写字母、小写字母还是其他字符 | ASCII 码比较、多分支 |
| `华氏温度转换器.c` | 输入摄氏温度，按 F = C × 9/5 + 32 输出华氏温度 | 浮点数、算术表达式 |

## 环境

- 编辑器：VS Code
- 编译器：MinGW-w64
- 系统：Windows 11

## 如何运行

```bash
gcc 文件名.c -o 文件名.exe
./文件名.exe
```

所有源码统一使用 UTF-8 编码，并且都能用 gcc 的默认标准直接编译，不需要额外的 `-std` 参数。
